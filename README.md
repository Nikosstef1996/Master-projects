PySpark_Log_Analysis.ipynb: Use of PySpark to analyse a simulated log file of 100 entries and extract meaningful information by use of functions such as map, reduce, filter, takeOrdered.

Similarity_Measures.ipynb: Implemented four similarity measures from scratch for a document of words: Cosine similarity, Jaccard similarity, Manhattan similarity, Euclidean similarity, We computed TF-IDF manually and applied it to the cosine similarity.Compared results between the measures.

Wine_dataset_classifiers.ipynb: Classification in a wine dataset with LogisticRegression, KNeighborsClassifier, MultinomialNB,DecisionTreeClassifier, RandomForestClassifier and used various metrics such as : Confusion Matrix, precision, recall, f1-score.

SAT_Results.ipynb: For a dataset of SAT results of 478 schools applied EDA and PCA for finding the best schools. Moreover, we used clustering techniques such as t-sne and DBSCAN to find the best cluster.

Clustering_of_Images.ipynb: Clustering of 400 images with 4096 dimensions (Pixels) with unsupervised clustering methods such as Isomap, LocallyLinearEmbedding, t-sne, DBSCAN and dimensionality reduction techniques such as PCA and vanilla PCA.

Bank_data_binary_target.ipynb: We use classification techniques such as : LogisticRegression, KNeighborsClassifier, DecisionTreeClassifier and RandomForestClassifier to classify dataset with features Marriage status, Amount of credit given in the credit card, gender and age and target whether he'll go bankrupt or not. Moreover, we use various measures to assess the accuracy of the classification such as confusion matrices, precision, recall and f1-score.
